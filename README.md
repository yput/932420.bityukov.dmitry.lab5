# Задание:
## Реализовать интерактивные функции:
<ul>
  <li>Поиск элементов через getElementById, querySelector, querySelectorAll</li>
  <li>Манипуляции с DOM: изменение текста, атрибутов, классов; добавление/удаление элементов.</li>
  <li>Переключение темы (светлая/тёмная) по кнопке.</li>
  <li>Скрытие/показ блоков по клику.</li>
  <li>Обработка ошибок: проверка существования элемента.</li>
  <li>Сохранение состояния в localStorage: при добавлении/удалении элементов и переключении темы сохранять данные; при загрузке страницы восстанавливать их.</li>
</ul>
  
## Вариант 6. Тема «Любитель кино и сериалов» (список фильмов к просмотру)
Контент: строки таблицы (название, год, статус «к просмотру/просмотрено»). Логика:
кнопка «Добавить фильм» создаёт новую строку "tr" с ячейками "td". Кнопка «Очистить
список» удаляет все строки из "tbody". Переключение темы, скрытие таблицы по клику.
Проверка существования элементов перед манипуляциями.
